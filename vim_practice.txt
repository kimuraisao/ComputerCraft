====================================
Vim 基本練習ファイル
====================================

このファイルを vim で開いて練習しましょう。
開き方: vim vim_practice.txt


------------------------------------
【ステップ1】モードの切り替え
------------------------------------
Vimには主に3つのモードがあります。

- ノーマルモード : 移動やコマンド入力(起動時はこのモード)
- 挿入モード     : 文字を入力するモード( i で入る)
- コマンドモード : 保存や終了などを行う( : で入る)

まずは Esc キーを何度か押して、ノーマルモードに戻る練習をしてみてください。


------------------------------------
【ステップ2】カーソル移動 (ノーマルモード)
------------------------------------
矢印キーの代わりに以下を使います。

    h : 左
    j : 下
    k : 上
    l : 右

下の行の上でカーソルを h j k l だけで自由に動かしてみましょう。

    ここは移動練習用のテキストです。上下左右に動いてみてください。
    あいうえお かきくけこ さしすせそ たちつてと なにぬねの


------------------------------------
【ステップ3】単語単位・行単位の移動
------------------------------------
    w : 次の単語の先頭へ
    b : 前の単語の先頭へ
    0 : 行の先頭へ
    $ : 行の末尾へ
    gg : ファイルの先頭へ
    G  : ファイルの末尾へ

下の行で w と b を繰り返して、単語間のジャンプを確認してみましょう。

    Vim practice is fun once you learn the basic motions.


------------------------------------
【ステップ4】挿入モードに入る
------------------------------------
    i : カーソルの位置に挿入
    a : カーソルの後ろに挿入
    o : 下に新しい行を作って挿入
    O : 上に新しい行を作って挿入

次の行の空欄に、好きな単語を i や a を使って入力してみてください。

    練習: [ここに何か入力してみる]


------------------------------------
【ステップ5】削除・変更
------------------------------------
    x  : カーソル位置の1文字を削除
    dd : 行全体を削除
    dw : カーソル位置から単語末尾までを削除
    cw : 単語を変更(削除して挿入モードへ)
    u  : 元に戻す(アンドゥ)
    Ctrl + r : やり直し(リドゥ)

下の行にはわざと不要な文字(XXX)を入れてあります。
x や dw を使って削除してみましょう。

    このXXX行にはXXX余分なXXX文字が入っていXXXます。


------------------------------------
【ステップ6】コピー・貼り付け
------------------------------------
    yy : 1行コピー(ヤンク)
    p  : カーソルの下に貼り付け
    P  : カーソルの上に貼り付け

下の行を yy でコピーして、別の行の下に p で貼り付けてみましょう。

    コピー練習用の行です。


------------------------------------
【ステップ7】検索と置換
------------------------------------
    /検索語  : 前方検索( n で次、N で前へ)
    :%s/old/new/g : ファイル全体で old を new に置換

下の行で "practice" という単語を検索してみてください。
コマンド: /practice

    This is a practice line. Practice makes perfect.
    Let's practice searching in this practice file.


------------------------------------
【ステップ8】保存と終了
------------------------------------
    :w        : 保存
    :q        : 終了(変更がなければ)
    :wq  または  ZZ : 保存して終了
    :q!       : 変更を破棄して終了

このファイルを編集したら、最後に :wq で保存終了してみましょう。


====================================
練習メニュー(自分でチェックしてみよう)
====================================
[ ] hjkl だけでファイル内を自由に移動できた
[ ] w, b, 0, $ で単語・行移動ができた
[ ] i, a, o で文字を挿入できた
[ ] x, dd, dw で削除ができた
[ ] u でアンドゥができた
[ ] yy と p でコピー&貼り付けができた
[ ] / で検索ができた
[ ] :wq で保存終了できた

すべてチェックできたら、Vimの基本操作は卒業です!
